# 此刻课表导入扩展

支持 Edge 和 Chrome 的 Manifest V3 版本。

安装：

1. 打开 `edge://extensions` 或 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载解压缩的扩展”，选择整个 `extension` 目录。
4. 打开扩展详情中的“扩展选项”，填写 Supabase 地址、匿名公钥和网页地址。
5. 登录 `http://61.131.228.75/jsxsd/` 并打开“我的课表”。
6. 点击页面右下角“导入到此刻”，确认预览后写入云端。

如果导入时提示需要密钥，直接在弹出的面板中输入与网页登录相同的空间密钥。扩展只保存 Supabase 会话，不保存明文密钥。
